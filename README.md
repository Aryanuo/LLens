## 🎯 Problem Statement

9 in 10 indian adults cannot fully understand their own medical lab reports. patients get a page of jargon and numbers with no explanation of what it means or what to do next-leading to anxiety, ignored red flags, and no follow through on diet, exercise, or lifestyle change.

## 🚀 Getting Started

### 1. Install Dependencies

```bash
npm install
```

### 2. Configure Environment

```bash
cp server/.env.example server/.env
```

### 3. Run Development Servers

- **Frontend:** `npm run dev:client`
- **Backend:** `npm run dev:server`
